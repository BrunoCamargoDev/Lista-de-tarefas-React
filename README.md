# ✅ Lista de Tarefas em React

Este é um projeto simples em React para gerenciar tarefas.  
Ele serve como prática para aprender conceitos como **useState**, **eventos**, **input controlado** e **listas**.

---

## 📌 Funcionalidades
- Adicionar tarefas
- Remover tarefas
- Lista dinâmica
- Evita adicionar tarefas vazias

---

## 📂 Estrutura do projeto
📂 src/  
  ├── App.jsx # Componente principal  
  ├── main.jsx # Entrada do React  
📂 public/  
  └── index.html  HTML base  
  
package.json # Dependências e scripts  


---

## 🚀 Como rodar o projeto
### 1. Clone este repositório:
```bash
git clone https://github.com/BrunoCamargoDev/Lista-de-tarefas-React.git
```

### 2. Entre na pasta do projeto:

```bash
cd Lista-de-tarefas-React
```

### 3. Instale as dependências:

```bash
npm install
```

### 4. Rode o projeto:

```bash
npm run dev
```

- Abra o link que aparecer no terminal (ex: http://localhost:5173) no seu navegador.
